--------------------------------------------------------------------------------
SLIDE 2: THE PROBLEM
--------------------------------------------------------------------------------

The Data Access Gap

- 80% of business users cannot write SQL or use BI tools
- Data teams are bottlenecked answering ad-hoc report requests
- Existing BI tools require weeks of training and setup
- Critical decisions are delayed because data is locked behind technical barriers
- Spreadsheet exports get stale the moment they're created

Result: Slow decisions, frustrated teams, underused data.


--------------------------------------------------------------------------------
SLIDE 3: THE SOLUTION
--------------------------------------------------------------------------------

MITR AI -- Talk to Your Data

A conversational AI layer that sits on top of your existing databases
and turns natural language into live data, charts, and dashboards.

How it works:
1. USER ASKS  --> "Show me monthly revenue by region"
2. AI UNDERSTANDS --> NLP engine classifies intent, extracts parameters
3. DATA FETCHED --> Connects to your SQL Server, Oracle, CSV/XLSX, or REST APIs
4. RESULTS DELIVERED --> Tables, charts, drill-downs -- all in one chat window

No migration. No data movement. Connects to what you already have.

[Screenshot: 03-chat-data-results.png or 02-chat-query-results.png]

--------------------------------------------------------------------------------

AI Chat Interface

- Ask questions in plain English
- Context-aware follow-up conversations
- Smart suggestions based on usage patterns and time of day
- Dynamic filters (date ranges, departments, regions)

- CSV/XLSX file upload for instant analysis

Interactive Dashboards

SLIDE 6: KEY FEATURES -- DATA EXPLORATION
--------------------------------------------------------------------------------

Grid Board & Data Explorer

Grid Board (Spreadsheet-like editor):
- Inline cell editing with full change tracking
- Multi-column sorting, filtering, row grouping
- Pivot tables for cross-tabulation
- Find & Replace across all cells
- CSV/XLSX import and export

Data Explorer:
- Point-and-click analysis of any connected data source
- Auto-generated insights: trends, outliers, correlations
- 16 built-in ML features running directly in the browser

--------------------------------------------------------------------------------
SLIDE 7: KEY FEATURES -- ENTERPRISE READY
--------------------------------------------------------------------------------

Built for the Enterprise

Multi-Tenant Architecture:
- Separate groups with independent NLP models and data access
- Role-based access control (Admin, Builder, Viewer)
- Per-user data scoping and preferences

Data Connectors:
- Microsoft SQL Server
- Oracle Database
- CSV / XLSX files (with auto-detection)
- REST APIs (Bearer, NTLM, BAM token auth)

Security & Compliance:
- AES-256-GCM encrypted audit logs
- Full audit trail with user attribution
- No data leaves your infrastructure

[Screenshot: 08-admin-panel.png + 15-admin-connectors.png]


--------------------------------------------------------------------------------
SLIDE 8: KEY FEATURES -- SELF-LEARNING & MONITORING
--------------------------------------------------------------------------------

Gets Smarter Over Time

Self-Learning Engine:
- Learns from every user interaction
- Auto-promotes high-confidence patterns
- Collaborative filtering for personalized suggestions
- Admin review queue for low-confidence classifications

Anomaly Detection:
- Automated monitoring with statistical and seasonal detection
- Anomaly badges on dashboard cards
- Configurable sensitivity thresholds
- Proactive alerts when metrics deviate

Embeddable Widget:
- Drop a chat widget into any existing web app with one line of code
- Full feature parity with the main interface

--------------------------------------------------------------------------------
SLIDE 9: ARCHITECTURE & DEPLOYMENT
--------------------------------------------------------------------------------

Flexible Deployment

Architecture:
  Next.js Frontend --> Express.js Engine --> Your Databases
                                         --> Your REST APIs
                                         --> Your CSV/XLSX Files

Deployment Options:
- On-premise (Windows Server, Linux)
- Docker / Docker Compose
- Cloud (any container platform)
- Hybrid setups

Tech Stack:
- Frontend: Next.js, React, TypeScript
- Backend: Express.js, Node.js
- NLP: nlp.js with per-group corpus training
- Charts: Recharts with 6+ visualization types
- Auth: Role-based with multi-tenant isolation
